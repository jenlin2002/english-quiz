假設語氣

Conditionals & Wishes
If I were…I wish…

本單元目標與暖身

學完這個單元，你會

  • 分辨「可能成真」和「與事實相反」的假設
  • 寫出與現在相反（were、would + V）
  • 寫出與過去相反（had p.p.、would have p.p.）
  • 用 should 說「萬一」
  • 用 wish 說「真希望…」，分清楚 wish 和 hope

暖身 3 題

1If it ____ tomorrow, I'll stay home. (rains / will rain)rains
2If I ____ you, I would rest. (am / were)were
3I wish I ____ fly. (can / could)could

先看全貌：有可能嗎？

種類if 子句主要子句例句
事實、真理現在式現在式
If you heat ice, it melts. （冰加熱就會融化）
可能成真現在式will + V
If it rains, I will stay home. （下雨的話我就待在家）
與現在相反過去式（were）would + V
If I were rich, I would buy a house. （如果我有錢就會買房子）
與過去相反had + p.p.would have + p.p.
If I had studied, I would have passed. （如果我當時用功就會及格）
和事實相反時，動詞要往過去退一格。

有可能成真的假設

事實、真理：兩邊現在式

zero conditional
If you mix red and blue, you get purple.
→ 永遠如此
If I drink coffee at night, I can't sleep.
→ 每次都這樣

未來可能：if 現在式 + will

first conditional
If it is sunny tomorrow, we will go on a picnic.
→ 不是 if it will be
If you need help, call me.
→ 也可以接祈使句

與現在事實相反

If + 過去式, would + V

現在不是這樣
If I had wings, I would fly to Japan.
→ 事實：我沒有翅膀
If I knew her number, I could call her.
→ 事實：我不知道
If I were you, I would take a break.
→ be 一律用 were，常用來給建議

事實怎麼說

假設 ⇄ 事實
If I were taller, I could reach it.
→ 假設
= I am not tall enough, so I can't reach it.
→ 事實：現在式、肯否相反

與過去事實相反

If + had p.p., would have p.p.

過去已經發生
If you had told me, I would have helped you.
→ 你當時沒說
If I had left earlier, I wouldn't have missed the bus.
→ 我當時沒早點出門

事實怎麼說

假設 ⇄ 事實
If he had studied, he would have passed.
→ 假設
= He didn't study, so he didn't pass.
→ 事實：過去式、肯否相反

混合的假設與「萬一」

過去沒做，影響現在

mixed

If + had p.p.（過去）, would + V + now（現在）

If I had eaten breakfast, I wouldn't be hungry now.
→ 早上沒吃，現在很餓

看時間線索：if 子句 last week；主要子句 now

萬一：If + should + V

should
If it should rain, the game will be canceled.
→ 萬一下雨
If you should see Ken, tell him to call me.
→ 萬一看到 Ken

wish：真希望…

希望公式例句
現在wish + 過去式（were）
I wish I were a bird. （真希望我是一隻鳥）
現在（能力）wish + could + V
I wish I could fly. （真希望我會飛）
過去wish + had + p.p.
I wish I had studied harder. （真希望我當時更用功）
真的有可能 → hopehope + will
I hope it will be sunny tomorrow. （希望明天會放晴）

學生最常錯的 5 句

1
If it will rain tomorrow, we will stay home. → If it rains tomorrow, we will stay home.
if 子句現在代未來。
2
If I am you, I would apologize. → If I were you, I would apologize.
與現在相反用 were。
3
If I had money, I will buy it. → If I had money, I would buy it.
主要子句用 would。
4
If you had called, I would come.（昨天） → If you had called, I would have come.
與過去相反。
5
I wish I can fly. → I wish I could fly.
wish 後面退一格。
