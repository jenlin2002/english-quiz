WEEK 7 · GRAMMAR

條件句進階：第二、三類與混合

Second & Third Conditionals
If I were…If I had…

本週目標與暖身

本週目標

  • 用第二類條件句談「與現在事實相反」的假設
  • 用第三類條件句談「與過去事實相反」的假設
  • 用混合條件句連接過去的原因與現在的結果
  • 用 unless、as long as、in case、otherwise 表達條件

暖身 3 題

1If I ____ you, I would study harder. (am / were)were
2If I had studied, I would ____ passed. (have / had)have
3I won't go ____ you come with me. (unless / if)unless

回收：第一期的零與第一條件句

第一期學過兩類「可能發生」的條件句；這週學「不可能」或「已經不能改變」的兩類。

零條件句

一般事實

公式：If + 現在式，現在式

If you heat ice, it melts.
→ 冰一加熱就融化

第一條件句

未來可能

公式：If + 現在式，will + 原形

If it rains tomorrow, we will stay home.
→ 如果明天下雨，我們就待在家

第二類條件句：與現在事實相反

公式

Second conditional

If 子句：過去式（be 動詞一律用 were）

主要子句：would / could + 原形

意思：現在沒有這件事，只是想像

If I were you, I would study harder.
→ 如果我是你，我會更用功（我不是你）
If she had more money, she would buy a new car.
→ 如果她有更多錢，她會買新車（她沒錢）

更多例句

If I won the lottery, I would buy a big house.
→ 如果我中樂透，我會買大房子
I would travel around the world if I had more time.
→ 如果有更多時間，我會環遊世界

第三類條件句：與過去事實相反

公式

Third conditional

If 子句：had + 過去分詞

主要子句：would have + 過去分詞

意思：過去已經發生，不能改變，只能後悔或想像

If I had studied harder, I would have passed the test.
→ 如果我當時更用功，就會及格了（其實沒有）
If he had left earlier, he would have caught the train.
→ 如果他早點出門，就趕上火車了

更多例句

If we had checked the map, we wouldn't have gotten lost.
→ 如果我們有看地圖，就不會迷路了
She would have called you if she had remembered.
→ 她如果記得，就會打給你了

混合條件句：過去的原因，現在的結果

公式

Mixed conditional

If 子句：had + 過去分詞（過去）

主要子句：would + 原形（現在）

意思：過去如果不同，現在也會不同

If I had studied medicine, I would be a doctor now.
→ 如果當時學醫，我現在就是醫生了
If he hadn't eaten so much last night, he wouldn't be sick now.
→ 如果他昨晚沒吃那麼多，現在就不會不舒服

怎麼判斷

看時間詞：if 子句有 last night、yesterday、in 2020，主要子句有 now、today、these days，就是混合條件句。
If I had gone to bed earlier, I wouldn't be so tired today.
→ 如果我昨天早點睡，今天就不會這麼累

四類條件句總整理

類型If 子句主要子句意思
零條件現在式現在式一般事實
第一條件現在式will + 原形未來可能
第二條件過去式（were）would + 原形與現在事實相反
第三條件had + p.p.would have + p.p.與過去事實相反
混合條件had + p.p.would + 原形過去原因，現在結果

unless、as long as、in case、otherwise

連接詞意思例句
unless除非（= if … not）
I won't go unless you come with me.
→ 除非你跟我去，否則我不去
as long as只要
You can borrow my bike as long as you return it.
→ 只要你歸還，就可以借我的腳踏車
in case以防萬一
Take an umbrella in case it rains.
→ 帶把傘以防下雨
otherwise否則
Hurry up, otherwise you will miss the bus.
→ 快點，否則你會錯過公車

對比頁：容易搞混的四組

were 與 was

If I were you, …
→ 第二類條件句 be 動詞一律用 were
If I was you, …
→ 口語偶爾聽到，考試用 were

if 與 unless

If you don't hurry, you'll be late.
→ 如果你不快點
Unless you hurry, you'll be late.
→ 除非你快點（unless 後面不再加 not）

if 與 in case

If it rains, I'll stay home.
→ 如果下雨，我就待在家
I'll take an umbrella in case it rains.
→ 我帶傘，以防下雨（不管有沒有下）

would 與 would have

If I were rich, I would travel.
→ 現在的假設
If I had been rich, I would have traveled.
→ 過去的假設

學生最常錯的 5 句

1
If I would be rich, I would travel. → If I were rich, I would travel.
if 子句裡不用 would，第二類用過去式或 were。
2
If I studied harder, I would have passed. → If I had studied harder, I would have passed.
第三類的 if 子句要用 had + 過去分詞。
3
If he had left earlier, he would catch the train. → If he had left earlier, he would have caught the train.
第三類的主要子句要用 would have + 過去分詞。
4
I won't go unless you don't come. → I won't go unless you come.
unless 本身就是否定，後面不再加 not。
5
Take an umbrella unless it rains. → Take an umbrella in case it rains.
「以防萬一」用 in case，不是 unless。

挑錯練習與句型轉換

挑錯：每句有一個錯

1If I would have time, I would help you.would have → had
2If it hadn't rained, we would go yesterday.would go → would have gone
3I will call you unless I don't have time.刪掉 don't

轉換

1I'm not rich, so I can't buy a car.（第二類）If I were rich, I could buy a car.
2I didn't study, so I failed.（第三類）If I had studied, I wouldn't have failed.
3Don't be late, or you'll miss the show.（用 otherwise）Don't be late, otherwise you'll miss the show.

在閱讀與聽力裡找到它

If she chose medicine, her parents would be very proud. “If I had followed my heart, I would have become a musician,” Ken told her. “I will choose music unless my parents are against it.”

閱讀怎麼用

  • 看到 If 加過去式，是現在的假設
  • 看到 If 加 had p.p.，是過去的後悔
  • unless、otherwise 後面常是作者的結論

聽力怎麼用

  • 聽到 were 或 had p.p.，表示說的是假的、想像的事
  • 聽到 would have，表示事情已經過去了
  • 聽到 in case，表示「為了預防」，不是「如果」

口說句型跟讀

先按 🔊 聽，再跟著大聲念，最後換成自己的假設。

If I won a million dollars, I would travel around the world.
→ 第二類
If I were you, I would go to bed early.
→ 建議
If I had studied harder, I would have passed the test.
→ 第三類
I take an umbrella in case it rains.
→ in case
I will go unless it rains.
→ unless

重點整理與測驗說明

類型公式
第二類If + 過去式，would + 原形
第三類If + had p.p.，would have + p.p.
混合If + had p.p.，would + 原形
unless= if … not，後面不再加 not
in case以防萬一
口訣：現在假的用過去式，過去假的用 had p.p.；if 子句裡不放 would。
